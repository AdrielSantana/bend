WebGPU shader compile test

Each test only compiles shaders: nothing runs on the GPU. Outside Windows it compiles the run the page uses there, never the copy made for Direct3D, which Metal chokes on. Open one test at a time, in order. If the browser freezes, the last line shown (and the tab's title) tells where.

  • chain: small shaders whose calls, once inlined, make 640 to 10 million lines
  • fly: Fly's shader for Direct3D (23 thousand lines inlined)
  • boss: Slash Boss's shader for Direct3D (120 thousand inlined; the whole kernel was 2.3 million)
  • craft-typed: Bendcraft's shader for Direct3D, with typed picks (184 thousand inlined)
  • craft: Bendcraft's shader for Direct3D, as the game is (304 thousand inlined; the whole kernel was 160 million)
