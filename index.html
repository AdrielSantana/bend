Bend 2 on WebGPU

Each page is a Bend 2 program built into WebAssembly with the page target (bendlang/bend#866). Its parallel call, !, runs on your GPU through WebGPU. The WGSL is translated from the runtime's own device C, so the same program runs natively on Metal and CUDA, and here in the browser.

Each page's status line reports whether its ! ran on WebGPU. Each also links to the same page on the CPU cores (?gpu=off), for comparison.

  • GPU · cores Bendcraft: an endless voxel world, a ray per pixel. Try a 1470×796 frame.
  • GPU · cores Bendcraft's bench: the render's ! timed at six sizes, 512×512 to 1920×1080.
  • GPU · cores Fly: ray-marched spheres with hard shadows, a 1024×1024 frame from one !.
  • GPU · cores Slash Boss 3D: a boss fight over a small 3D library, its frame drawn by one !.
  • GPU · cores Parallel sort: a bitonic sort of 216 numbers; prints one line.
  • GPU · cores Parallel sum: a fork/join sum of 216 numbers; prints one line.

Needs WebGPU (Chrome or Edge on the desktop, recent Safari) and SharedArrayBuffer. Without WebGPU, the ! runs on the cores. GitHub Pages sends no COOP/COEP headers, so a small service worker adds them, and the first visit reloads once.

Source: the webgpu branch of AdrielSantana/bend (bend2/wgsl.ts). Bendcraft: AdrielSantana/bendcraft.
